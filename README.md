# 🎲 Trio Website

Official website for **Trio**, a strategic mathematics board game that combines logic, arithmetic, and competitive gameplay.

🌐 **Website:** https://trio-game.com

---

## About Trio

Trio is a strategy-based mathematical board game designed to improve logical thinking, mental arithmetic, and decision-making while providing an enjoyable multiplayer experience.

Players combine numbers using mathematical operations to reach target values, making every round both educational and competitive.

## Local Development

Clone the repository:

```bash
git clone git@github.com:hasan-aydinoglu/trio-web-lastVersion.git
```

Open the project:

```bash
cd trio-web-lastVersion
```

Deploy using Firebase:

```bash
firebase deploy
```
